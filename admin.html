First time? How to get your access key
  1. Sign in at github.com with the account that holds the site.
  2. Go to Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. Name it “Studio site admin”, set expiration to 1 year, and under Repository access choose Only select repositories → the site’s repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate, copy the key that starts with github_pat_, and paste it above.
